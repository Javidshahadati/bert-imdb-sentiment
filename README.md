# BERT IMDb Sentiment Analysis

## 📌 توضیح
یک مدل BERT (DistilBERT) برای تحلیل احساسات نظرات فیلم IMDb. مدل تشخیص می‌دهد نظر **مثبت** است یا **منفی**.

## 🎯 نتیجه
- دقت (Accuracy): ۸۷.۴۰٪
- F1: ۸۷.۳۰٪
- Precision: ۸۵.۹۱٪
- Recall: ۸۸.۷۳٪
- داده: ۲۰۰۰ نمونه آموزش + ۱۰۰۰ تست (از IMDb)
- پارامترها: ۶۶,۹۵۵,۰۱۰
- زمان آموزش: ~۱ دقیقه (GPU T4)

## 🛠️ تکنولوژی
- Hugging Face Transformers
- DistilBERT (distilbert-base-uncased)
- PyTorch
- Kaggle (GPU T4)

## 🧠 نحوه‌ی کار
۱. دیتاست IMDb بارگذاری می‌شود.
۲. متن‌ها با توکنایزر DistilBERT به توکن تبدیل می‌شوند.
۳. مدل از پیش آموزش‌دیده با داده‌ی جدید Fine-tune می‌شود.
۴. مدل روی داده‌های تست ارزیابی می‌شود.
۵. متن‌های جدید پیش‌بینی می‌شوند.

## 📊 نتایج تست
| متن | نتیجه | اطمینان |
|------|--------|----------|
| "absolutely amazing" | 😊 مثبت | ۹۶.۷٪ |
| "Terrible film" | 😞 منفی | ۹۷.۱٪ |
| "It was okay, not great but not bad" | 😞 منفی | ۶۴.۵٪ |
| "best performances" | 😊 مثبت | ۹۶.۶٪ |
| "so boring" | 😞 منفی | ۹۲.۸٪ |

## 📝 درس‌های گرفته‌شده
- Fine-tuning یک مدل از پیش آموزش‌دیده، با داده‌ی کم هم نتیجه‌ی خوبی می‌دهد.
- مدل روی جملات **مبهم** (مثل «It was okay») اطمینان پایین دارد — این رفتار **درست** است.
- مدل روی جملات **واضح** اطمینان بالا دارد.
- هشدار `MISSING/UNEXPECTED` در بارگذاری، طبیعی است (لایه‌ی آخر از نو ساخته می‌شود).
